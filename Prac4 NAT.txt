PRACTICAL - NAT
---------------

TOPOLOGY / ADDRESSING

R1:
Inside interface: Fa0/0
Outside interface: S0/0/0

R1 addresses from the practical:
Fa0/0: 192.168.1.1
S0/0/0: 10.0.0.1

PC0: 192.168.1.2
Default Gateway: 192.168.1.1

PC1: 192.168.1.3
Default Gateway: 192.168.1.1

Server: 192.168.10.1

⚠️ CHECK:
The handwritten page has unclear/incomplete R1-R2 serial addressing. Verify the actual serial IP addresses from the topology before configuring routing/NAT.


R1 CONFIGURATION
----------------

enable
configure terminal
interface f0/0
ip nat inside
exit
interface s0/0/0
ip nat outside
ip nat inside source static 192.168.1.2 10.0.0.1
ip nat inside source static 192.168.1.3 10.0.0.1
ip nat outside source static 10.0.0.1 10.0.0.2
exit



end
