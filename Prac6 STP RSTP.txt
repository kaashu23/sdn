⚠️ CHECK THIS COMMAND:
spanning-tree mode pvst

The practical is labelled STP/RSTP, but PVST is not RSTP. If the practical specifically requires RSTP, use:
spanning-tree mode rapid-pvst

The handwritten command is preserved above.


⚠️ CHECK:
ip address 10.0.0.1 255.0.0.0
ip address 10.0.0.2 255.0.0.0

These use a /8 mask. If the addressing table specifies /24, use:
ip address 10.0.0.1 255.255.255.0
ip address 10.0.0.2 255.255.255.0

The handwritten commands are preserved above.


⚠️ CHECK:
interface range g1/0/11 - 24
interface range g1/0/1, g1/0/5 - 6
interface range f0/1 - 24, g1/0/1 - 2
interface range f0/1 - 4

These depend on the exact switch model and physical topology. Verify that the interfaces exist and match the connections.


⚠️ CHECK:
interface range f0/1 - 4
switchport mode trunk

The handwritten page indicates these ports as trunk ports. Verify that all four ports are actually switch-to-switch/uplink connections before using this range.
