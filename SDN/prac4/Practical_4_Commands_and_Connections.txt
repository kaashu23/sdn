PRACTICAL 4 - CISCO PACKET TRACER
Commands, Connections and Verification

============================================================
EXPERIMENT 1: GRE TUNNEL CONFIGURATION
============================================================

TOPOLOGY / CONNECTIONS
----------------------

PC0 Fa0  <-->  SW0 Fa0/1
PC1 Fa0  <-->  SW0 Fa0/2
SW0 Fa0/24  <-->  R1 Fa0/0
R1 Fa0/1  <-->  R2 Fa0/0
R2 Fa0/1  <-->  R3 Fa0/0
R3 Fa0/1  <-->  SW1 Fa0/24
SW1 Fa0/1  <-->  PC2 Fa0
SW1 Fa0/2  <-->  PC3 Fa0

Use Copper Straight-Through for PC-to-Switch and Switch-to-Router
connections. For router-to-router connections, use the appropriate
cable available in Packet Tracer.

IP ADDRESSING
-------------

PC0: 192.168.1.2
Subnet Mask: 255.255.255.0
Default Gateway: 192.168.1.1

PC1: 192.168.1.3
Subnet Mask: 255.255.255.0
Default Gateway: 192.168.1.1

PC2: 192.168.2.2
Subnet Mask: 255.255.255.0
Default Gateway: 192.168.2.1

PC3: 192.168.2.3
Subnet Mask: 255.255.255.0
Default Gateway: 192.168.2.1

R1 Fa0/0: 192.168.1.1
R1 Fa0/1: 10.0.0.1

R2 Fa0/0: 10.0.0.2
R2 Fa0/1: 20.0.0.1

R3 Fa0/0: 20.0.0.2
R3 Fa0/1: 192.168.2.1

R1 Tunnel1: 50.50.50.1/24
R3 Tunnel1: 50.50.50.2/24


R1 CONFIGURATION
----------------

enable
configure terminal
hostname R1

interface fastethernet0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit

interface fastethernet0/1
ip address 10.0.0.1 255.255.255.252
no shutdown
exit

ip route 20.0.0.0 255.255.255.252 10.0.0.2

interface tunnel 1
ip address 50.50.50.1 255.255.255.0
tunnel source fastethernet0/1
tunnel destination 20.0.0.2
tunnel mode gre ip
no shutdown
exit

ip route 192.168.2.0 255.255.255.0 50.50.50.2

end
write memory


R2 CONFIGURATION
----------------

enable
configure terminal
hostname R2

interface fastethernet0/0
ip address 10.0.0.2 255.255.255.252
no shutdown
exit

interface fastethernet0/1
ip address 20.0.0.1 255.255.255.252
no shutdown
exit

end
write memory


R3 CONFIGURATION
----------------

enable
configure terminal
hostname R3

interface fastethernet0/0
ip address 20.0.0.2 255.255.255.252
no shutdown
exit

interface fastethernet0/1
ip address 192.168.2.1 255.255.255.0
no shutdown
exit

ip route 10.0.0.0 255.255.255.252 20.0.0.1

interface tunnel 1
ip address 50.50.50.2 255.255.255.0
tunnel source fastethernet0/0
tunnel destination 10.0.0.1
tunnel mode gre ip
no shutdown
exit

ip route 192.168.1.0 255.255.255.0 50.50.50.1

end
write memory


GRE VERIFICATION
----------------

show ip interface brief
show interfaces tunnel 1
show ip route
ping 50.50.50.2
ping 192.168.2.2

From PC0:

ping 192.168.2.2
ping 192.168.2.3
tracert 192.168.2.2


============================================================
EXPERIMENT 2: VTP CONFIGURATION
============================================================

TOPOLOGY / CONNECTIONS
----------------------

SW0 Fa0/1  <-->  SW1 Fa0/1
SW0 Fa0/2  <-->  SW2 Fa0/1
SW2 Fa0/2  <-->  SW3 Fa0/1

VTP ROLES
---------

SW0 = VTP SERVER
SW1 = VTP CLIENT
SW2 = VTP TRANSPARENT
SW3 = VTP CLIENT

VTP DOMAIN = VTPServer
VTP VERSION = 2
VLAN = 10
VLAN NAME = department


SW0 - VTP SERVER
----------------

enable
configure terminal
hostname SW0

vtp version 2
vtp domain VTPServer
vtp mode server

interface fastethernet0/1
switchport mode trunk
no shutdown
exit

interface fastethernet0/2
switchport mode trunk
no shutdown
exit

vlan 10
name department
exit

end
write memory


SW1 - VTP CLIENT
----------------

enable
configure terminal
hostname SW1

vtp version 2
vtp domain VTPServer
vtp mode client

interface fastethernet0/1
switchport mode trunk
no shutdown
exit

end
write memory

============================================================
EXPERIMENT 3: STATIC NAT CONFIGURATION
============================================================

TOPOLOGY / CONNECTIONS
----------------------

PC0 Fa0  <-->  SW0 Fa0/1
PC1 Fa0  <-->  SW0 Fa0/2
SW0 Fa0/24  <-->  R0 Fa0/1
R0 S0/0/0  <-->  R1 S0/0/0
R1 Fa0/1  <-->  SW1 Fa0/24
SW1 Fa0/1  <-->  Server Fa0

If using a serial DCE cable, set the clock rate on the DCE side.

IP ADDRESSING
-------------

PC0: 192.168.1.2
Subnet Mask: 255.255.255.0
Default Gateway: 192.168.1.1

PC1: 192.168.1.3
Subnet Mask: 255.255.255.0
Default Gateway: 192.168.1.1

R0 Fa0/1: 192.168.1.1
R0 S0/0/0: 10.0.0.1

R1 S0/0/0: 10.0.0.2
R1 Fa0/1: 172.16.1.1

Server: 172.16.1.2
Subnet Mask: 255.255.255.0
Default Gateway: 172.16.1.1


R0 - STATIC NAT
---------------

enable
configure terminal
hostname R0

interface fastethernet0/1
ip address 192.168.1.1 255.255.255.0
ip nat inside
no shutdown
exit

interface serial0/0/0
ip address 10.0.0.1 255.255.255.252
clock rate 64000
ip nat outside
no shutdown
exit

ip nat inside source static 192.168.1.2 10.0.0.10
ip nat inside source static 192.168.1.3 10.0.0.11

ip route 172.16.1.0 255.255.255.0 10.0.0.2

end
write memory


R1 CONFIGURATION
----------------

enable
configure terminal
hostname R1

interface serial0/0/0
ip address 10.0.0.2 255.255.255.252
no shutdown
exit

interface fastethernet0/1
ip address 172.16.1.1 255.255.255.0
no shutdown
exit

ip route 10.0.0.8 255.255.255.248 10.0.0.1

end
write memory


NAT VERIFICATION
----------------

On R0:

show ip interface brief
show ip nat translations
show ip nat statistics
show ip route

From PC0:

ping 172.16.1.2

From PC1:

ping 172.16.1.2

version 2
no auto-summary

exit

R3 CONFIGURATION
----------------

enable
configure terminal

router rip
version 2
no auto-summary

IMPORTANT
---------

The uploaded Practical 4 document contains some incomplete/mistyped
commands, especially in the NAT section. The commands above are
organized into complete command blocks for Packet Tracer practice.

The GRE section in the source specifies:
R1 Tunnel1 = 50.50.50.1
R3 Tunnel1 = 50.50.50.2

The VTP section specifies:
SW0 = Server
SW1 = Client
SW2 = Transparent
SW3 = Client

The NAT section in the source contains an incomplete second static
NAT command and an incomplete default-route command. Those incomplete
