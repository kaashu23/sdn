PRACTICAL 5 - IMPLEMENT INTER-VLAN ROUTING
Cisco Packet Tracer
Commands, Connections, IP Addressing and Verification

SOURCE BASIS
------------
This practical is the Cisco Networking Academy lab "Implement Inter-VLAN Routing".
The lab uses Router-on-a-Stick with VLANs 10, 20, 30, 999 and 1000.

IMPORTANT:
The uploaded document contains a few interface-name differences between the
topology/addressing table and the example command pages. The topology and
addressing table show a Cisco 4221-style interface G0/0/1, while the later
example commands show F0/0. The commands below follow the topology/addressing
table and use R1 G0/0/1, which is the interface shown in the practical.

============================================================
1. TOPOLOGY / PHYSICAL CONNECTIONS
============================================================

R1 G0/0/1  <-->  S1 F0/5
S1 F0/1   <-->  S2 F0/1
PC-A NIC  <-->  S1 F0/6
PC-B NIC  <-->  S2 F0/18

The topology diagram in the document shows:
- R1 connected to S1 through R1 G0/0/1 and S1 F0/5.
- S1 connected to S2 through S1 F0/1 and S2 F0/1.
- PC-A connected to S1 F0/6.
- PC-B connected to S2 F0/18.

NOTE ABOUT THE UPLOADED LAB:
The VLAN assignment table later in the document lists S1 F0/3 for VLAN 20
and S2 F0/2 for VLAN 30, while the topology picture labels the PCs as
F0/6 and F0/18. Follow the interface assignment required by your Packet
Tracer file/instructor. The configuration below follows the VLAN table
because those ports are explicitly specified for VLAN 20 and VLAN 30.

============================================================

The lab specifies unused S1 ports F0/4-24 and G0/1-2 for VLAN 999
and administrative shutdown.

switchport mode access
switchport access vlan 999
shutdown
exit

15. S1 - TRUNK TO S2
============================================================

S1 F0/1 is the trunk between S1 and S2.

interface fastethernet0/1
switchport mode trunk
switchport trunk native vlan 1000
switchport trunk allowed vlan 10,20,30,1000
no shutdown
exit

end
write memory

end

Verify:

============================================================
19. R1 - ROUTER-ON-A-STICK CONFIGURATION
============================================================

The addressing table specifies R1 G0/0/1 as the physical interface and
G0/0/1.10, G0/0/1.20, G0/0/1.30 and G0/0/1.1000 as subinterfaces.

Start with the physical interface:

enable
configure terminal

interface gigabitethernet0/0/1
no shutdown
exit

============================================================
20. R1 - VLAN 10 SUBINTERFACE
============================================================

interface gigabitethernet0/0/1.10
description VLAN 10 Management
encapsulation dot1q 10
ip address 192.168.10.1 255.255.255.0
exit

============================================================
21. R1 - VLAN 20 SUBINTERFACE
============================================================

interface gigabitethernet0/0/1.20
description VLAN 20 Sales
encapsulation dot1q 20
ip address 192.168.20.1 255.255.255.0
exit

============================================================
22. R1 - VLAN 30 SUBINTERFACE
============================================================

interface gigabitethernet0/0/1.30
description VLAN 30 Operations
encapsulation dot1q 30
ip address 192.168.30.1 255.255.255.0
exit

============================================================
23. R1 - NATIVE VLAN 1000 SUBINTERFACE
============================================================

The native VLAN subinterface must NOT have an IP address.

interface gigabitethernet0/0/1.1000
description NATIVE
encapsulation dot1q 1000 native
exit

end
write memory

============================================================
24. VERIFY ROUTER SUBINTERFACES
============================================================

show ip interface brief

You should see:

G0/0/1.10     192.168.10.1
G0/0/1.20     192.168.20.1
G0/0/1.30     192.168.30.1
G0/0/1.1000   unassigned

The physical interface G0/0/1 must be up/up for Router-on-a-Stick
communication to work.

29. INTER-VLAN ROUTING TEST FROM PC-A
============================================================

Test PC-B:

Test S2 management:

Test S1 management:

============================================================
30. TEST FROM PC-B
============================================================

Open PC-B -> Desktop -> Command Prompt.

Test PC-A:

ping 192.168.20.3

Test its gateway:

ping 192.168.30.1

Then run:

tracert 192.168.20.3

The traffic should pass through the router's VLAN 30 gateway
192.168.30.1 and then reach PC-A through VLAN 20.

32. COMMON ERRORS TO CHECK
============================================================

ERROR 1:
PC cannot ping its gateway.

CHECK:
- PC IP address
- PC subnet mask
- PC default gateway
- Correct access VLAN on the switch port
- Router physical interface is no shutdown
- Correct router subinterface exists

ERROR 2:
PC-A can ping its gateway but cannot ping PC-B.

CHECK:
- VLAN 20 and VLAN 30 exist
- S1-S2 trunk is working
- S1-R1 trunk is working
- VLANs 10,20,30,1000 are allowed on trunks
- Native VLAN is 1000 on both ends
- Router subinterfaces have correct 802.1Q encapsulation

ERROR 3:
Native VLAN mismatch.

Use on both trunk ends:

switchport trunk native vlan 1000

ERROR 4:
VLAN is missing.

Check:

show vlan brief

ERROR 5:
Trunk is not working.

Check:

show interfaces trunk

Then verify:

switchport mode trunk
switchport trunk native vlan 1000
switchport trunk allowed vlan 10,20,30,1000
