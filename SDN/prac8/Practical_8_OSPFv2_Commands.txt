12. PART 2 - CONFIGURE OSPF ON R1
============================================================

The source specifies OSPF process ID 56 and router ID 1.1.1.1.

On R1:

enable
configure terminal

router ospf 56
router-id 1.1.1.1
network 10.53.0.0 0.0.0.255 area 0
exit

end
write memory

IMPORTANT:
At this stage, the source does NOT advertise R1 Loopback1 into OSPF.
R1's Loopback1 is used later as the exit interface for the default
static route.

============================================================
13. PART 2 - CONFIGURE OSPF ON R2
============================================================

The source specifies OSPF process ID 56 and router ID 2.2.2.2.

network 192.168.1.0 0.0.0.255 area 0

============================================================
17. PART 3 - OPTIMIZATION ON R1
============================================================

The source asks R1 to:
1. Set OSPF priority to 50.
2. Set OSPF hello interval to 30 seconds.
3. Configure a default static route using Loopback1.
4. Propagate the default route into OSPF.

On R1:

enable
configure terminal

interface gigabitethernet0/0/1
ip ospf priority 50
ip ospf hello-interval 30
exit

ip route 0.0.0.0 0.0.0.0 loopback1

router ospf 56
default-information originate
exit

end
write memory

============================================================
18. WHY THE DEFAULT ROUTE WORKS
============================================================

R1 uses Loopback1 as the exit interface for the static default route:

0.0.0.0/0 -> Loopback1

Then OSPF command:

default-information originate

causes R1 to advertise the default route into OSPF.

R2 can therefore learn the default route from R1.

============================================================
19. R2 - CONFIGURE LOOPBACK1 AS POINT-TO-POINT
============================================================

The source asks R2 to make OSPF treat Loopback1 as a point-to-point
network.

On R2:

enable
configure terminal

interface loopback1
ip ospf network point-to-point
exit

end
write memory

The source states that this results in OSPF advertising Loopback1
using the interface subnet mask instead of the previous host-route
behavior.

============================================================
20. R2 - MAKE LOOPBACK1 PASSIVE
============================================================

The source asks R2 to prevent OSPF advertisements from being sent
toward the Loopback1 network.

On R2:

enable
configure terminal

router ospf 56
passive-interface loopback1
exit

end
write memory

IMPORTANT:
passive-interface loopback1 still allows the Loopback1 network to be
advertised by OSPF, but prevents OSPF hello packets from being sent
out that interface.

============================================================
21. CHANGE OSPF REFERENCE BANDWIDTH
============================================================

The source instructs changing the OSPF reference bandwidth to 1 Gbps
on EACH router.

On R1:

enable
configure terminal

router ospf 56
auto-cost reference-bandwidth 1000
exit

end

On R2:

enable
configure terminal

router ospf 56
auto-cost reference-bandwidth 1000
exit

end

The source then instructs you to restart OSPF using:

clear ip ospf process

============================================================
22. RESTART OSPF PROCESS
============================================================

On R1:

clear ip ospf process

When prompted:

Reset ALL OSPF processes? [no]:

Type:

yes

Then repeat on R2:

clear ip ospf process

When prompted:

Reset ALL OSPF processes? [no]:

Type:

yes

WARNING:
This temporarily resets the OSPF process and the adjacency will
re-form. Wait for the neighbor relationship to become FULL again.

============================================================
37. IMPORTANT NOTES FROM THE SOURCE
============================================================

1. The source uses Cisco 4221 routers with IOS XE 16.9.4 in the
   documented lab.

2. The source topology uses G0/0/1 on both routers.

3. The command appendix at the end of the source uses F0/0 for the
   router interface. This is an interface-model difference. For the
   Cisco 4221 topology shown in the document, use G0/0/1.

4. The source states that the routers and switches should be erased
   and have no startup configurations before beginning.

5. OSPF process ID is 56.

6. R1 router ID is 1.1.1.1.

7. R2 router ID is 2.2.2.2.

8. OSPF area is 0.

9. R1 provides the default route to R2 using Loopback1.

10. The source's note says the static routing approach used in this
    lab is for assessing OSPF configuration and may not represent
    networking best practices.

============================================================

IF OSPF NEIGHBOR IS NOT FORMED:

show ip interface brief

show ip ospf interface gigabitethernet0/0/1

Verify both sides have:

and OSPF:

network 10.53.0.0 0.0.0.255 area 0

Also ensure G0/0/1 is:

up/up

------------------------------------------------------------

IF R2 LOOPBACK IS NOT LEARNED BY R1:

On R2:

show ip route connected
show ip ospf
show ip route ospf

Verify:

network 192.168.1.0 0.0.0.255 area 0

------------------------------------------------------------

IF R2 DOES NOT LEARN THE DEFAULT ROUTE:

On R1:

show ip route
show running-config | section router ospf

Verify:

ip route 0.0.0.0 0.0.0.0 loopback1

and:

default-information originate

On R2:

show ip route ospf

------------------------------------------------------------

IF OSPF CHANGES DO NOT APPEAR AFTER REFERENCE BANDWIDTH:

On both routers:

clear ip ospf process

Confirm with:

yes

Then wait for:

show ip ospf neighbor

to show the adjacency as FULL.
