15. R1 - MULTI-AREA OSPF CONFIGURATION
============================================================

configure terminal

router ospf 1
router-id 1.1.1.1

network 192.168.1.0 0.0.0.255 area 1
network 192.168.2.0 0.0.0.255 area 1
network 192.168.12.0 0.0.0.3 area 0

passive-interface loopback1
passive-interface loopback2

exit

============================================================
16. R1 - DEFAULT ROUTE TO SIMULATED INTERNET
============================================================

The source uses Lo0 as the exit interface for the default route.

ip route 0.0.0.0 0.0.0.0 loopback0

Then advertise the default route into OSPF:

router ospf 1
default-information originate
exit

end
copy running-config startup-config

The source notes that the default-route warning about using a
non-point-to-point interface may appear when Loopback0 is used.
This is expected in the lab.

27. COMMON PRACTICAL CHECKS
============================================================

IF SERIAL INTERFACE IS DOWN:

Check:

show ip interface brief

Verify:

no shutdown

On DCE interfaces verify:

clock rate 128000

On ALL serial interfaces verify:

bandwidth 128

------------------------------------------------------------

IF OSPF NEIGHBOR IS NOT FULL:

Check:

show ip ospf neighbor
show ip ospf interface brief
show ip protocols

Verify both routers have the correct serial network in the same OSPF
area.

R1-R2:
192.168.12.0/30 must be Area 0.

R2-R3:
192.168.23.0/30 must be Area 3.

------------------------------------------------------------

IF LOOPBACK ROUTE IS MISSING:

Check:

show ip route connected
show ip protocols

Verify the correct network statement and area.

------------------------------------------------------------

IF R2/R3 CANNOT REACH R1 LOOPBACK:

On R1 verify:

ip route 0.0.0.0 0.0.0.0 loopback0

and:

router ospf 1
default-information originate

Then on R2/R3:

show ip route ospf

============================================================
28. IMPORTANT SOURCE NOTE
============================================================

The source's addressing table on page 1 specifies:

R3 Lo4 = 192.168.4.1 /24
R3 Lo5 = 192.168.5.1 /24

However, the command appendix on pages 7-8 contains a few lines with
different/incomplete masks, including a Lo4 /30 line and a Lo5 network
statement with 0.0.0.3.

For this TXT, the MAIN configuration follows the addressing table and
topology at the beginning of the uploaded lab:
Lo4 = 192.168.4.1 255.255.255.0
Lo5 = 192.168.5.1 255.255.255.0

Do not mix the appendix's apparent mask typo into the main configuration.
