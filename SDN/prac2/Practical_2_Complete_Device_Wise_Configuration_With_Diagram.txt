ACTUAL ROUTER PORTS
-------------------
R1:
  FastEthernet0/1  -> S1
  Serial0/0/0      -> ISP Serial0/0/0

ISP:
  Serial0/0/0      -> R1 Serial0/0/0
  Serial0/0/1      -> R3 Serial0/0/0

R3:
  FastEthernet0/1  -> S3
  Serial0/0/0      -> ISP Serial0/0/1

SWITCH PORTS
------------
S1:
  FastEthernet0/2  -> R1 FastEthernet0/1
  One other FastEthernet port -> PC-A

S3:
  FastEthernet0/2* -> R3 FastEthernet0/1
  One other FastEthernet port -> PC-C

* The uploaded practical/source confirms the router-to-switch links and
  the actual 1841 router interfaces, but it does not record the exact S3
  switch port used. If your working Packet Tracer file uses another active
  S3 port, keep that actual port instead of changing it.

CABLE / WIRE TYPE
============================================================

1. PC-A NIC -> S1 FastEthernet0/x
   Cable: Copper Straight-Through

2. S1 FastEthernet0/2 -> R1 FastEthernet0/1
   Cable: Copper Straight-Through

   Cable: Serial DCE/DTE
   Clock rate: R1 side (DCE)

4. ISP Serial0/0/1 -> R3 Serial0/0/0

5. R3 FastEthernet0/1 -> S3 FastEthernet0/2* 
   Cable: Copper Straight-Through

6. S3 FastEthernet0/x -> PC-C NIC
   Cable: Copper Straight-Through

PRACTICAL 2
CONFIGURING AND VERIFYING STANDARD IPv4 ACLs
=============================================

DEVICE-WISE COMPLETE CONFIGURATION
Cisco 1841 / Packet Tracer

IMPORTANT:
1. This file contains the COMPLETE configuration from an empty device:
   basic configuration + interfaces + routing + ACLs + verification.
2. Interface names are adapted to the Cisco 1841 setup used:
      R1  -> FastEthernet0/1, Serial0/0/0
      R3  -> FastEthernet0/1, Serial0/0/0
      ISP -> Serial0/0/0, Serial0/0/1
3. In the original lab sheet, R3 uses Serial0/0/1, but your actual
   Cisco 1841 uses Serial0/0/0 for the R3-ISP serial link.
4. Clock rate is configured only on the DCE serial interfaces used in
   your setup:
      R1 S0/0/0
      ISP S0/0/1
5. PC IP addresses are entered from Desktop -> IP Configuration.
6. Do the connectivity tests BEFORE applying ACLs when performing the
   practical step-by-step. The final ACL configuration is included below.


============================================================
R1 - COMPLETE CONFIGURATION
============================================================

enable
configure terminal

no ip domain-lookup
hostname R1
service password-encryption
enable secret class

banner motd #
Unauthorized access is strictly prohibited.#

line console 0
password cisco
login
logging synchronous
exit

line vty 0 4
password cisco
login
exit

interface loopback 0
ip address 192.168.20.1 255.255.255.0
exit

interface fastEthernet 0/1
ip address 192.168.10.1 255.255.255.0
no shutdown
exit

interface serial 0/0/0
ip address 10.1.1.1 255.255.255.252
clock rate 128000
no shutdown
exit

router rip
version 2
network 192.168.10.0
network 192.168.20.0
network 10.1.1.0
no auto-summary
exit

end

R3 - NUMBERED STANDARD ACL 1
============================================================

Policy:
Allow 192.168.10.0/24 and 192.168.20.0/24
to access 192.168.30.0/24.

enable
configure terminal

access-list 1 remark Allow R1 LANs Access
access-list 1 permit 192.168.10.0 0.0.0.255
access-list 1 permit 192.168.20.0 0.0.0.255
access-list 1 deny any

interface fastEthernet 0/1
ip access-group 1 out
exit

end
copy running-config startup-config

============================================================
IMPORTANT PRACTICAL NOTES
============================================================

1. Standard ACLs filter traffic using the SOURCE IP address.
2. ACL 1 is applied on R3 FastEthernet0/1 OUT.
3. BRANCH-OFFICE-POLICY is applied on R1 FastEthernet0/1 OUT.
4. The ISP router does NOT have an ACL.
5. The numbered ACL contains an explicit deny any.
6. The modified named ACL contains an explicit deny any.
7. If your serial interface is different, use the actual interface
   shown by:
   show ip interface brief
8. Verify the DCE side before setting clock rate:
   show controllers serial 0/0/0
   or the appropriate serial interface.
9. Save every completed configuration with:
   copy running-config startup-config
