5. R1 - BASIC CONFIGURATION
================================================

enable
configure terminal

hostname R1
no ip domain-lookup

interface Serial0/0/1
ip address 198.133.219.1 255.255.255.248
no shutdown
exit

end
copy running-config startup-config

================================================
6. R2 - BASIC CONFIGURATION
================================================

enable
configure terminal

hostname R2
no ip domain-lookup

interface Serial0/0/0
ip address 198.133.219.2 255.255.255.248
no shutdown
exit

interface Serial0/0/1
ip address 209.165.200.2 255.255.255.252
clock rate 128000
no shutdown
exit

end
copy running-config startup-config

IMPORTANT:
The source identifies R2 S0/0/1 as DCE.
Therefore, configure the clock rate on R2 S0/0/1.

================================================
7. ISP-1 - CONFIGURATION FROM THE SOURCE
================================================

enable
configure terminal

hostname ISP-1
no ip domain-lookup

interface Loopback0
ip address 10.10.10.10 255.255.255.255
exit

interface Serial0/0/1
ip address 209.165.200.1 255.255.255.252
no shutdown
exit

ip route 0.0.0.0 0.0.0.0 Loopback0

router bgp 65001
bgp log-neighbor-changes
network 0.0.0.0
neighbor 209.165.200.2 remote-as 65000
exit

end
copy running-config startup-config

25. eBGP QUICK REVISION
================================================

eBGP means External BGP.

It is used between different Autonomous Systems.

This lab uses:

Company:
AS 65000

ISP:
AS 65001

eBGP peer:

R2 209.165.200.2
        |
        |
ISP-1 209.165.200.1

R2 configuration:

router bgp 65000
neighbor 209.165.200.1 remote-as 65001
network 198.133.219.0 mask 255.255.255.248

ISP configuration:

router bgp 65001
network 0.0.0.0
neighbor 209.165.200.2 remote-as 65000

================================================
26. WHAT EACH COMMAND DOES
================================================

router bgp 65000

Starts BGP process for AS 65000.

------------------------------------------------

neighbor 209.165.200.1 remote-as 65001

Defines ISP-1 as the external BGP neighbor and identifies its
Autonomous System as 65001.

------------------------------------------------

network 198.133.219.0 mask 255.255.255.248

Advertises the Company's 198.133.219.0/29 prefix through BGP.

------------------------------------------------

network 0.0.0.0

Advertises the default route from ISP-1.

------------------------------------------------

show ip bgp summary

Quickly verifies BGP neighbor status and received prefixes.

------------------------------------------------

show ip bgp

Displays the BGP routing table.

------------------------------------------------

show ip route

Displays the IP routing table and confirms whether the BGP routes
are installed.
