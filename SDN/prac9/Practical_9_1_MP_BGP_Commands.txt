18. R1 - MP-BGP CONFIGURATION
================================================

enable
configure terminal

router bgp 1000
bgp router-id 1.1.1.1

neighbor 10.1.2.2 remote-as 500
neighbor 10.1.3.3 remote-as 300
neighbor 10.1.3.130 remote-as 300

neighbor 2001:db8:acad:1012::2 remote-as 500
neighbor 2001:db8:acad:1013::3 remote-as 300
neighbor 2001:db8:acad:1014::3 remote-as 300

address-family ipv4 unicast
neighbor 10.1.2.2 activate
neighbor 10.1.3.3 activate
neighbor 10.1.3.130 activate
exit

address-family ipv6 unicast
neighbor 2001:db8:acad:1012::2 activate
neighbor 2001:db8:acad:1013::3 activate
neighbor 2001:db8:acad:1014::3 activate
exit

end

38. IMPORTANT: WHAT NOT TO ADVERTISE
================================================

The source explicitly notes that the networks between routers are
NOT advertised in eBGP.

Do not add network statements for:

10.1.2.0/24
10.1.3.0/25
10.1.3.128/25
10.2.3.0/24

Only the AS prefixes/loopback networks are advertised.

41. IF BGP IS NOT ESTABLISHED - CHECK IN THIS ORDER
================================================

1. Check interfaces:

show ip interface brief
show ipv6 interface brief

2. Ping the neighbor IPv4 address.

3. Check BGP configuration:

show running-config | section router bgp

4. Check neighbors:

show bgp all neighbors

5. Confirm remote AS numbers.

6. Confirm IPv6 routing is enabled:

show running-config | include ipv6 unicast-routing

7. Confirm IPv4 and IPv6 neighbors are activated under the
correct address families.

IPv4:

address-family ipv4 unicast
neighbor X.X.X.X activate

IPv6:

address-family ipv6 unicast
neighbor XXXX:XXXX::X activate

43. INTERFACE-NAME NOTE FROM THE UPLOADED LAB
================================================

The main addressing/topology section uses:

G0/0/0
G0/0/1
S0/1/0
S0/1/1

The lab's command appendix also shows alternate interface identifiers
such as:

G2/0
G3/0
Serial1/0
Serial1/1

and later:

GigabitEthernet1/0
GigabitEthernet2/0
Serial3/0
Serial3/1

These are interface-name variants shown for different router/platform
layouts in the source.

For the topology/addressing table, use the interface names actually
present on your Packet Tracer router. Check with:

show ip interface brief

Then substitute the corresponding interface name while keeping the
same IP addresses.

Do NOT change the IP addressing, AS numbers, neighbor IPs, or BGP
configuration logic.
