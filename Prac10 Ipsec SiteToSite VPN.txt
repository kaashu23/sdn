PRACTICAL 10 - IPSEC SITE-TO-SITE VPN

TOPOLOGY / ADDRESSING

R1 -------- R2 -------- R3

PC0:
IP address: 192.168.1.3
Default gateway: 192.168.1.1

PC1:
IP address: 192.168.2.3
Default gateway: 192.168.2.1

PC2:
IP address: 192.168.3.3
Default gateway: 192.168.3.1

VPN:
R1 <---------------- IPsec VPN ----------------> R3

R1 VPN peer:
10.2.2.2

R3 VPN peer:
10.1.1.2

Protected networks:
R1 LAN: 192.168.1.0/24
R3 LAN: 192.168.3.0/24


R1

enable
configure terminal
access-list 110 permit ip 192.168.1.0 0.0.0.255 192.168.3.0 0.0.0.255
crypto isakmp policy 10
encryption aes 256
authentication pre-share
group 5
exit
crypto isakmp key vpnpass address 10.2.2.2
crypto ipsec transform-set VPN-SET esp-aes esp-sha-hmac
crypto map VPN-MAP 10 ipsec-isakmp
description VPN connection to R3
set peer 10.2.2.2
set transform-set VPN-SET
match address 110
exit
interface s0/0
crypto map VPN-MAP
exit
end
show crypto isakmp sa


R3

enable
configure terminal
access-list 110 permit ip 192.168.3.0 0.0.0.255 192.168.1.0 0.0.0.255
crypto isakmp policy 10
encryption aes 256
authentication pre-share
group 5
exit
crypto isakmp key vpnpass address 10.1.1.2
crypto ipsec transform-set VPN-SET esp-aes esp-sha-hmac
crypto map VPN-MAP 10 ipsec-isakmp
description VPN connection to R1
set peer 10.1.1.2
set transform-set VPN-SET
match address 110
exit
interface s0/0
crypto map VPN-MAP
exit
end
show crypto isakmp sa


IMPORTANT CHECKS

⚠️ CHECK:
crypto isakmp key vpnpass address 10.2.2.2

On R1, the address must be the reachable outside/VPN interface address of R3.

⚠️ CHECK:
crypto isakmp key vpnpass address 10.1.1.2

On R3, the address must be the reachable outside/VPN interface address of R1.

⚠️ CHECK:
interface s0/0

The exact serial interface must match the interface connected toward the VPN peer. If your topology uses a different serial interface, use that interface.

⚠️ CHECK:
crypto map VPN-MAP 10 ipsec-isakmp

This is the correct crypto-map syntax. The crypto map must then be applied to the appropriate outside interface with:
crypto map VPN-MAP

⚠️ CHECK:
encryption aes 256

This is valid on IOS images that support AES-256 for IKE. If the practical's router image does not accept AES-256, the command will need to be changed to an algorithm supported by that image.

⚠️ CHECK:
crypto ipsec transform-set VPN-SET esp-aes esp-sha-hmac

This is valid IOS transform-set syntax. Both VPN peers must use compatible transform-set parameters.


ROUTING / REACHABILITY

⚠️ IMPORTANT:
The handwritten page says to add the router addresses to RIP and to check the routing, but the actual RIP commands are not written on these pages.

The R1 peer address 10.2.2.2 and R3 peer address 10.1.1.2 must be reachable before the IPsec tunnel can establish.

Do not enter the following as literal commands:
"add ip address in RIP"
"check properly"

These are notes/instructions, not IOS commands.
