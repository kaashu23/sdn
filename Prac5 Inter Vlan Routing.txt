R1 - ROUTER-ON-A-STICK

enable
configure terminal
interface f0/0
no shutdown
exit

interface f0/0.10
description vlan 10
encapsulation dot1q 10
ip address 192.168.10.1 255.255.255.0
exit

interface f0/0.20
description vlan 20
encapsulation dot1q 20
ip address 192.168.20.1 255.255.255.0
exit

interface f0/0.30
description vlan 30
encapsulation dot1q 30
ip address 192.168.30.1 255.255.255.0
exit

interface f0/0.1000
description native
encapsulation dot1q 1000
exit

interface f0/0
no shutdown
exit

show ip interface brief


⚠️ CHECK THESE COMMANDS / ITEMS FROM THE HANDWRITTEN PAGE

interface range f0/4 - 27 , g0/1 - 2

Reason: Cisco IOS interface-range syntax and available interfaces depend on the switch model. The handwritten notes use both FastEthernet and GigabitEthernet ranges. If the switch does not have g0/1 or g0/2, those interfaces will fail. Configure only interfaces that actually exist on your switch.

⚠️ CHECK:
shutdown all remaining ports

Reason: This is an instruction/note, not a Cisco IOS command. It should NOT be entered literally at the CLI. The actual interface-range commands below it perform the shutdown.

⚠️ CHECK:
interface range f0/3 - 29 , g0/1 - 2

Reason: Same interface-availability issue as above. Verify the S2 model and use only existing ports.

⚠️ CHECK:
interface f0/1
interface f0/2

The exact trunk/access port numbers must match the physical topology. From the handwritten topology, R1-S1, S1-S2, and the PC ports are assigned to specific FastEthernet ports; verify them against your Packet Tracer/GNS3 topology.

⚠️ CHECK:
interface f0/0.1000
encapsulation dot1q 1000

The notes use VLAN 1000 as the native VLAN on the switches, but the router subinterface is written without the `native` keyword. If VLAN 1000 is intended to be the native VLAN on the router-on-a-stick link, the router configuration should normally be:

interface f0/0.1000
encapsulation dot1q 1000 native

The handwritten command is retained above and flagged rather than removed.

IMPORTANT:
The router's physical interface must be up (`no shutdown`), while the individual subinterfaces provide the VLAN gateway IP addresses. IEEE 802.1Q router-on-a-stick configuration uses subinterfaces with `encapsulation dot1q` and IP addresses for the VLAN gateways.
