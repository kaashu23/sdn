⚠️ CHECK THIS COMMAND / CONFIGURATION:

switchport nonegotiate

This is the correct Cisco IOS command spelling. If your handwritten command is intended as "switchport nonnegotiate", that spelling is incorrect. Use:
switchport nonegotiate


⚠️ CHECK:

S2:
channel-group 3 mode passive

S3:
channel-group 3 mode passive

Both sides of an LACP EtherChannel cannot be passive. At least one side must be active. Therefore, this configuration will NOT form an LACP EtherChannel if both sides remain passive.

Correct example:
S2:
channel-group 3 mode active

S3:
channel-group 3 mode passive

The handwritten passive commands are preserved above and flagged rather than removed.


⚠️ CHECK:

S1:
channel-group 1 mode desirable

S3:
channel-group 1 mode desirable

Both sides using PAgP desirable can form an EtherChannel, so this pairing is valid if these are the two ends of the same physical links.


⚠️ CHECK:

interface range g0/1 - 2, f0/21 - 22

The exact interfaces depend on the switch model and physical topology. Do not use an interface number that does not exist on your switch.


IMPORTANT ETHERCHANNEL RULE

All member interfaces of the same EtherChannel should have matching Layer-2 settings, including speed/duplex and trunk/access configuration. The physical interfaces should be configured consistently before forming the channel.
